# JavaPOOEstudo

# Estudo de caso em java - Programação orientada a objetos.

A atividade foi apresentada em sala, para medir as habilidades adquiridas durante as aulas, o intuito do professor era verificar se conseguiríamos desenvolver um projeto simples, sozinhos.

## O que foi solicitado ->

Situação:

Uma pequena escola decidiu criar um sistema simples para gerenciar cursos e alunos.

Cada curso possui várias informações, e cada aluno pode se matricular em um curso.

A escola quer organizar melhor esses dados usando programação orientada a objetos.

Objetivo da Atividade
Criar um programa que represente essa situação utilizando:
- Classes
- Objetos
- Atributos (de instância e de classe)
- Métodos

Requisitos do Sistema
Classe Cursos
Deve conter:

Atributos de instância:
- nome do curso
- carga horária
- valor da mensalidade

Atributo de classe:
- total de cursos criados

Métodos:
- exibir informações do curso - MostrarDadosCurso()

Classe Alunos
Deve conter:
Atributos de instância:
- ra
- nome do aluno
- email
- curso em que está matriculado

Atributo de classe:
- total de alunos cadastrados

Métodos:
- exibir dados do aluno - MostrarDadosAluno()

Relação entre as classes
- Um aluno deve estar associado a um objeto da classe Curso

Parte prática (o que o aluno deve fazer)
1 - Criar um projeto chamado: Escola
2 - Criar as classe Cursos (incluindo os getters e setters)
3 - Criar as classe Alunos (incluindo os getters e setters)
4 - Criar a classe principal (Main) contendo pelo menos:
  - Instanciar 2 objetos da classe cursos
  - Instanciar 2 objetos da classe alunos
  - Matricular cada aluno em um curso
4.1 - Carregar os métodos que exibem os dados de:
 - Dados dos cursos
   - Total de cursos cadastrados
 - Dados dos alunos
   - Total de alunos cadastrados
